# M.R.S. 0.53.0-preview1

- Commercial → Railroad decodes BCH-valid HOT/EOT frames from a tuned NFM receiver or M.R.S. I/Q replay. EOT displays the unit, pressure and status fields. HOT displays raw frame/type information while field meanings remain unresolved.
- Amateur → CW decodes conversational Morse audio into a continuous transcript with separate tone, character speed and spacing controls.
- Amateur → WEFAX captures grayscale weather fax images, with manual start/stop, IOC and line-rate selection, horizontal alignment, slant correction and PNG export.
- Analysis → Cellular survey reports spectrum energy and coverage within selected U.S. reference bands using the current HackRF capture.
- See Help/additional-receive.md for operation and limits.
