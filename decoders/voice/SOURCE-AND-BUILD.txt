The full DSD source tree also includes unrelated GPL D-Star files; these are not linked. See dsd/COPYRIGHT for the exact per-file terms and retained third-party notices.

Build with PowerShell and a MinGW-w64 x64 GCC toolchain:
  ./Sources/build.ps1 -Toolchain C:/path/to/mingw64/bin
The script builds mbelib C files and the minimal C++ wrapper plus DSD P25 FEC/Hamming files. It statically links compiler runtimes. Generated objects go under Sources/objects and are excluded from releases. No DSD executable or DSD-FME runtime is used.

mrs_voice.cpp exposes per-stream IMBE state, frame synthesis and P25 metadata FEC. The metadata encoder is for synthetic tests only. No radio hardware or transmit API is included. The host serializes FEC operations because upstream RS helpers retain mutable state. No encryption-key handling/decryption is implemented.
