# FT8 station checks

- Reopen the transmit dialog and confirm the callsign and grid persist.
- Select Even or Odd and check that the TX bursts start on the expected 15-second UTC boundaries, with one RX slot between bursts.
- Click the waterfall and confirm the red marker and RF preview follow the new TX offset. Select a received decode and check the green marker.
- In an automatic peer exchange, check that a reply advances the next message and that any missed decode deadline is shown as a hold.
- Confirm receive returns after the last burst or after HALT TX.
