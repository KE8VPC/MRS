# M.R.S. 0.51.0-preview2

- FT8 repeat follows the selected Even or Odd slot every 30 seconds. Each slot is 15 seconds. Automatic peer exchanges can hold a turn while reply decoding finishes.
- Select the transmit audio offset on the waterfall, or use a recent decode to set the offset and opposite slot. Red marks TX and green marks the selected RX offset.
- Callsign and grid are saved in the receiver workspace. Set the license class once under **Amateur → FT8 / FT4 / WSPR → TX station…**. The transmit dialog uses one **Arm TX** action for station confirmation.
- The transmit header shows the session limit.
