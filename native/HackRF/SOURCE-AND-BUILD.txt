Built with the existing MSYS2 MinGW64 x64 toolchain: GCC 16.2.0,
CMake and Ninja, libusb 1.0.30, winpthreads.
From a MinGW64 environment, with libusb headers/libraries available:
  cmake -S host/libhackrf -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_POLICY_VERSION_MINIMUM=3.5 -DLIBUSB_INCLUDE_DIR=/mingw64/include/libusb-1.0 -DLIBUSB_LIBRARIES=/mingw64/lib/libusb-1.0.dll.a
  cmake --build build
The resulting build/src/libhackrf.dll is distributed as hackrf.dll.
Copy libusb-1.0.dll and libwinpthread-1.dll from the same toolchain beside it.
No statically linked LGPL library is used. libusb's corresponding MSYS2
source package and build recipe are included under Sources. Native notices
are under Licenses. The M.R.S. loader uses an explicit absolute DLL path and
DLL-directory/system search flags, not arbitrary current-directory lookup.

driver installation, or automatic antenna-power enable. Native USB streaming
and actual H4M/Mayhem v2.4 compatibility still require station acceptance.
