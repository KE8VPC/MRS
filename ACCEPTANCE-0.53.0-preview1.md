# Station checks

- Commercial → Railroad. Replay an NFM I/Q recording on 457.9375 MHz. Confirm the EOT unit and pressure, input attribution and checksum result. Check 452.9375 MHz with a stronger independent HOT recording before accepting HOT field reception.
- Amateur → CW. Match the received tone and speed, then compare a live or recorded conversation with the transcript. Try a retune and confirm text remains visible and decoding stops at the source change.
- Amateur → WEFAX. Start capture on picture data, use the correct IOC and line rate, adjust alignment, and compare the saved PNG with the display.
- Analysis → Cellular survey. Start the HackRF and select a reference band. Compare its measured range with the spectrum. Retune outside it and confirm the view indicates no overlap.
