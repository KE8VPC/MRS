# M.R.S. application icon

User-approved concept: rounded navy tile, teal tuning-dial arc and three spectrum peaks, with a white tuning needle. No lettering.

Concept generated with the built-in image-generation tool in this project conversation, then approved by the user for project use. Source artwork: src/MRS-icon.png. Windows resource: src/MRS.ico (16, 24, 32, 48, 64, 128 and 256 pixels). The ICO preserves the generated artwork and transparency through size/format conversion.

Prompt summary: create one face-on Windows radio-workbench icon; deep navy #101722, teal #66DEBA, white needle aligned to tallest of three spectrum peaks; bold simple geometry, rounded square and transparent exterior; no text or tiny dial details.

The project embeds the icon in the executable and as a WPF window resource. Both receiver windows use it. Existing 0.12.2 release archives are unchanged; the icon is included at the next package build. Keep both artwork files in source packages.
