# Station checklist

1. In Aviation → Messages / Inspector, confirm an ACARS message shows its label, readable fields when available, and intact raw text and decoder JSON in the inspector.
2. Check a valid ACARS position report from the observed label 16 or 30 layouts. Confirm that both labelled layouts can resolve to 40.622, -85.034 in the supplied examples and that ACARS has its own map markers and trail.
3. In HDTV, confirm Diagnostics opens and closes, Clear diagnostics clears the log, and accepted/rejected packet counts remain visible in normal operation. Verify program discovery and playback against a known ATSC 1.0 signal.
4. FT8 station checks carry forward from ACCEPTANCE-0.51.0-preview2.md.
