# Burst and pulse inspection
Context: Bursts
Keywords: SCADA utility load control telemetry envelope timings audio tones 154.463

Burst inspection / narrow NFM detects activity and displays duration, pulse timing, envelope and candidate audio-frequency bins. Quiet pre-trigger samples support noise-floor estimation. Select a row to inspect/export. Margin changes apply at the next Start.

The supplied 154.463 MHz utility-like recording is not assigned a confirmed protocol. Detection of tone bins does not identify a vendor or decode a utility command. SCADA is an application category with many different protocols; this inspector is not a universal SCADA decoder.
