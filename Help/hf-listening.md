# HF listening, amateur CW beacons and HFGCS
Context: Analysis HF Beacons
Keywords: beacons NCDXF IBP CW HFGCS numbers stations HF shortwave schedules EAM SKYKING

Analysis → HF listening / beacons provides public listening references, receive tuning, source links and a manual observation log. Start a live receiver before tuning. The reference CSVs can also be imported through the frequency/bandplan manager. They do not contain local system data or grant any transmit permission.

The amateur beacon starter pack contains the five NCDXF/IARU International Beacon Project frequencies: 14.100, 18.110, 21.150, 24.930 and 28.200 MHz. Use CW. The schedule line shows the expected callsign for each band in the current ten-second slot using PC UTC; the eighteen-station sequence repeats every three minutes. It is not a received identification or an availability check. Check the original source for station outages and use received CW identification to establish what you actually heard. Regional/VHF/UHF beacon packs remain future reference work.

HFGCS is a military HF voice network, separate from numbers-station research. This starter dataset uses four channels from a dated 2022 USAF publication: 4724, 6739, 8992 and 11175 kHz, USB. Historical publication does not prove current activity, continuous simulcast or local reception. EAM and SKYKING are received message-format descriptions; a transmission does not establish its operational purpose or an inferred threat level. Voice transcription and group extraction are not included in this release.

The numbers-station buttons link to original monitoring directories/schedules. A third-party schedule is not copied into the product. Consult the source, add a local receive preset/frequency entry and keep a date with observations. Station designators, aliases, schedules and frequencies may be historical or inactive. An observed carrier alone does not identify a station. Message decryption is not provided.

Log current tuned frequency saves UTC, actual tuned frequency/mode, live/replay source and your note to hf-observations.csv in the current receiver's private workspace. It does not record audio automatically or label a scheduled station as confirmed. Use Recording/VOX separately for audio or I/Q. The log remains user data and is not included in clean release packages.
