# M.R.S. overview
Context: Overview
Keywords: workspaces tabs keyboard F1 help receive transmit

M.R.S. uses one source per receiver window. Receivers A–Z keep independent capture and analysis contexts; use Receivers to add and name workspaces.

## Workspaces
Spectrum holds the common RF display. Amateur contains AX.25/APRS. Commercial contains P25, DMR/LTR/NXDN and paging. Analysis contains sensors/meters/bursts, general observations/CW and Bandplans. Broadcast contains AM, FM, HD Radio and HDTV. Aviation has its aircraft table and map.

Press F1 or the ? button for offline help. Search matches keywords and function names across every topic. Clear the search box to browse the complete topic list.

Limited P25 Phase I C4FM and mapped Capacity Plus/Connect Plus/Tier III group following is under Commercial > Trunk following. Read its Help topic for mapping and hardware-retune limits. Decoded identifiers are evidence about a signal, not proof of its owner.
