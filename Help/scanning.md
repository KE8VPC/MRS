# Scanning and saved-folder scans
Context: Scan
Keywords: resume hold delay control frequency folder discover auto add birdies

Use Scan for signal discovery. Set noise-floor margin, channel width and discovery/save options before starting. Signals require repeat evidence before automatic addition. Birdie exclusions can suppress known receiver artifacts.

In Frequencies, right-click a folder and choose Scan to visit its saved channels. Use the folder scan hold/resume settings to prevent a continuous control carrier from holding indefinitely. Manual receiver tuning stops the scan. Review both squelch threshold and hold timing if scanning pauses too often or skips weak channels. P25/DMR trunk following is not implemented by folder scanning.
