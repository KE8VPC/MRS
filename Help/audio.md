# Audio input, listening and volume
Context: Audio
Keywords: WAV microphone speakers test tone monitor input gate volume

The Audio sidebar tab contains Windows input, WAV playback, Load test tone, output device, monitoring, volume and input gate. Starting another source replaces the current source for this receiver.

Enable audio monitoring to listen through the selected PC speakers/headphones. Volume controls listening gain. The input gate applies to audio-input/WAV sources; it is disabled for SDR reception. Recording and analysis receive the original input. SDR RF squelch is a separate control.

Choose PC speakers rather than a radio-connected output that could activate VOX. Recordings are controlled under Recording.
